# Version 3: Top-notch

**Goal:** modern-game quality for creators who want it: top-tier graphics, big worlds, online play.

**Proof it works:** a small team ships a polished, modern-looking game with the engine.

Builds on [Version 1](version-1.md) and [Version 2](version-2.md).

## What's included

### Graphics
- **High** quality: live bounce lighting, volumetric fog and clouds, very detailed models
- **Ultra / Cinematic** quality: ray-traced reflections and shadows, film-style effects
- A modern renderer (Vulkan, DirectX 12, Metal). This is the biggest engineering job in the whole project.
- Upscaling (DLSS, FSR); the game auto-detects the best setting for each player
- High-quality offline video rendering for trailers and films
- Advanced flowing-water simulation (pours and fills containers), off by default

### Characters
- **Character creator:** bases (human, elf, orc, robot, creature), sliders for body and face, hair, skin, scars, tattoos
- Clothes and armor that fit any body shape
- Optional **character creation screen** for players, with the creator choosing which sliders players get
- Import VRM characters (for example from VRoid Studio) and MakeHuman or Blender characters

### Big worlds and online
- Open worlds that load in pieces around the player
- **Online multiplayer:** co-op and versus templates, lobbies, invite a friend
- Achievements and leaderboards, with Steam and store integration

### Platforms
- Console export (PlayStation, Xbox, Switch). These need approval and dev kits from each company.

### Community and teams
- **Modding support:** players add their own levels, items and characters
- **Team collaboration:** several people on one project, see who changed what
- Unity package and prefab import (partial)
- More asset library sources with per-asset licenses (for example Sketchfab, Freesound, OpenGameArt)

### AI agents
- Full MCP toolset for Claude, Claude Code, Grok and other MCP-compatible tools: build scenes, write scripts, take screenshots, play-test, export
- Every AI change shows in the editor and can be undone; big actions need approval
